# Task 0.1 — Workspace skeleton

You are implementing part of `rust-use`: a Rust library of UI behaviors that AI agents use to
build and drive user interfaces (GPUI first). An architect reviews your work against the
acceptance criteria below. Do NOT run `git commit`; leave changes in the working tree.

## Goal
Create the Cargo workspace skeleton. No real functionality yet. Every crate compiles,
is documented, and is ready to be filled by later tasks.

  is NOT needed (workspace lint covers it).
- `rust-use-macros/src/lib.rs`: a doc comment only; no macros yet (it must still compile as a proc-macro crate with zero exports).
- Facade `crates/rust-use/src/lib.rs`:
  - Crate doc with a short intro and a ```` ```toml ```` snippet showing `rust-use = "0.1"` and the feature list (use `ignore`/`toml` fences so doctests pass).
