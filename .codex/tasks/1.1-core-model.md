# Task 1.1 — Core model: Behavior/Primitive traits, Ui registry, handles, actions, events

You are implementing part of `rust-use`, a Rust library of UI behaviors that AI agents use to
build and drive user interfaces (GPUI first). The headline goal is that an agent driving a UI
through rust-use needs far fewer tool calls and tokens than generic MCP UI automation. An
architect reviews your work against the contract below. **Do NOT run `git commit`.**
Work only in `crates/rust-use-core` (plus `Cargo.toml` dependency lines and the facade
re-exports noted at the end). If you lack network access, only use dependencies already in
`Cargo.lock`/registry cache: `serde`, `serde_json`, `thiserror` are declared in the workspace.

## Design overview

- A **behavior** is a piece of reusable interaction state + logic (selection, toggle, …).
- A **primitive** is a UI component the agent can see: a named behavior, mounted into a `Ui`.
  Primitives are composed of their own fields/actions plus embedded behaviors.
- The **Ui** is a thread-safe registry of mounted primitives. Every mounted primitive gets a
  stable numeric id (`@1`, `@2`, …, never reused within a `Ui`), an optional human label, and a
  revision number that bumps when it changes.
- Anything that changes state goes through an **action** (`invoke`) carrying a `ChangeSource`.
  Interceptors may veto an action before it runs; subscribers are notified after it ran.
- The agent bridge (later task, separate crate) is built ONLY on the public API you write here,
  so it must be sufficient: enumerate components with id/name/label/revision, describe them,
  list enabled actions with parameter names, invoke by ref, query long option lists, and get
  "what changed since revision N".

## Module layout (crates/rust-use-core/src)

```
lib.rs        crate docs + re-exports (flat: users write rust_use_core::Ui, not ::ui::Ui)
value.rs      Value alias, Args, FromArgs helpers
action.rs     ActionSpec, ParamSpec, ActionRequest, ChangeSource, Decision
describe.rs   Describe (attribute sink)
behavior.rs   Behavior + Primitive traits, Query/Page
ui.rs         Ui, Handle<T>, ComponentId, Ref, ComponentInfo, ChangeEvent, Subscription

```

## Exact public API (names and signatures are a contract — do not rename)

```rust
// value.rs
pub use serde_json::Value;                      // the dynamic value type everywhere

/// Positional action arguments.
#[derive(Debug, Clone, Default, PartialEq)]
pub struct Args(Vec<Value>);
impl Args {
    pub fn new() -> Self;
    pub fn from_vec(v: Vec<Value>) -> Self;
    pub fn len(&self) -> usize; pub fn is_empty(&self) -> bool;
    pub fn as_slice(&self) -> &[Value];
    /// Deserialize argument `index` (named `name` for error messages) into T.
    pub fn get<T: serde::de::DeserializeOwned>(&self, index: usize, name: &'static str) -> Result<T, ActionError>;
    /// Like `get` but missing → Ok(None).
    pub fn get_opt<T: serde::de::DeserializeOwned>(&self, index: usize, name: &'static str) -> Result<Option<T>, ActionError>;
}
impl From<()> for Args; impl From<Vec<Value>> for Args;
// Tuples up to 4 of T: serde::Serialize → Args, so users write step("Mute", "toggle", ()) or ("e2e4",)
// Implement via a macro: impl<A: Serialize> From<(A,)> for Args, etc. Serialization failures → Value::Null.

// action.rs
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum ChangeSource { User, Agent, Program }

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct ParamSpec { pub name: &'static str, pub ty: &'static str /* e.g. "str","int","bool","float","any" */, pub optional: bool }

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct ActionSpec { pub name: &'static str, pub doc: &'static str, pub params: &'static [ParamSpec] }

/// What interceptors see before an action runs.
#[derive(Debug)]
pub struct ActionRequest<'a> { pub id: ComponentId, pub component: &'static str /* primitive NAME */, pub label: Option<&'a str>, pub action: &'a str, pub args: &'a Args, pub source: ChangeSource }

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Decision { Allow, Deny(String) }   // impl From<bool> for Decision (false → Deny("denied"))

// describe.rs — the sink a behavior writes its visible state into
#[derive(Debug, Default, Clone, PartialEq)]
pub struct Describe { /* value: Option<Value>, attrs: Vec<(Cow<'static,str>, Value)> keeping insertion order */ }
impl Describe {
    pub fn new() -> Self;
    pub fn value(&mut self, v: impl serde::Serialize) -> &mut Self;          // the primary value (at most one; last wins)
    pub fn attr(&mut self, key: impl Into<Cow<'static, str>>, v: impl serde::Serialize) -> &mut Self;
    pub fn flag(&mut self, key: impl Into<Cow<'static, str>>, on: bool) -> &mut Self; // attr only when on (Value::Bool(true))
    pub fn primary(&self) -> Option<&Value>;
    pub fn attrs(&self) -> impl Iterator<Item = (&str, &Value)>;
    pub fn get(&self, key: &str) -> Option<&Value>;
}

// behavior.rs
/// Reusable interaction logic that exposes state and actions to agents.
pub trait Behavior: Send + 'static {
    /// Write agent-visible state.
    fn describe(&self, out: &mut Describe);
    /// Every action this behavior can ever perform (static list).
    fn actions(&self) -> Vec<ActionSpec> { Vec::new() }
    /// Whether `action` is currently available (e.g. `undo` with empty history → false). Default true.
    fn is_enabled(&self, action: &str) -> bool { let _ = action; true }
    /// Run `action`. Return None if this behavior does not own an action of that name
    /// (so composites can fall through to embedded behaviors), Some(result) otherwise.
    fn invoke(&mut self, action: &str, args: &Args) -> Option<Result<Value, ActionError>> { let _ = (action, args); None }
    /// Search a long option list. None = not queryable.
    fn query(&self, query: &Query) -> Option<Page> { let _ = query; None }
}

/// A behavior that can be mounted into a `Ui` as an agent-visible component.
pub trait Primitive: Behavior {
    /// Kebab-case component kind shown to agents, e.g. "mute-button".
    const NAME: &'static str;
}

#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct Query { pub text: Option<String>, pub from: usize, pub limit: usize /* 0 => default 50, cap 50 */ }
#[derive(Debug, Clone, Default, PartialEq)]
pub struct Page { pub items: Vec<Value>, pub total: usize, pub next: Option<usize> }
impl Query { pub fn effective_limit(&self) -> usize; /* applies default/cap */ }
impl Page { /// Build a page from an iterator, applying text filter is caller's job; from/limit applied here
            pub fn from_iter<I: IntoIterator<Item = Value>>(items: I, query: &Query) -> Self; }

// error.rs (thiserror)
#[derive(Debug, Clone, PartialEq, thiserror::Error)]
pub enum ActionError {
    #[error("missing argument `{0}`")] MissingArg(&'static str),
    #[error("invalid argument `{name}`: {reason}")] InvalidArg { name: &'static str, reason: String },
    #[error("action `{0}` is not available right now")] Disabled(String),
    #[error("{0}")] Rejected(String),               // domain error, e.g. "illegal move e2e5"
}
#[derive(Debug, Clone, PartialEq, thiserror::Error)]
pub enum ResolveError {
    #[error("no component matches `{0}`")] NotFound(String),
    #[error("`{query}` is ambiguous: {candidates:?}")] Ambiguous { query: String, candidates: Vec<ComponentId> },
}
#[derive(Debug, Clone, PartialEq, thiserror::Error)]
pub enum InvokeError {
    #[error(transparent)] Resolve(#[from] ResolveError),
    #[error("`{component}` has no action `{action}` (available: {available})")] UnknownAction { component: String, action: String, available: String /* comma-joined enabled actions */ },
    #[error("denied: {0}")] Denied(String),
    #[error(transparent)] Action(#[from] ActionError),
}

// ui.rs
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord)]
pub struct ComponentId(u32);          // Display: "@3"; FromStr accepts "@3" and "3"
impl ComponentId { pub fn get(self) -> u32; }

/// How callers address a component.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Ref { Id(ComponentId), Label(String) }
impl From<ComponentId> for Ref; impl From<&str> for Ref /* "@3" → Id, else Label */; impl From<String> for Ref;
// Label resolution order: exact label match; then case-insensitive label match; then primitive NAME
// match ("board") if exactly one component of that kind. Multiple matches → Ambiguous. Unmounted → NotFound.

#[derive(Debug, Clone, PartialEq)]
pub struct ComponentInfo { pub id: ComponentId, pub name: &'static str, pub label: Option<String>, pub revision: u64, pub describe: Describe, pub actions: Vec<ActionSpec> /* enabled only */ }

#[derive(Debug, Clone, PartialEq)]
pub struct ChangeEvent { pub id: ComponentId, pub revision: u64, pub source: ChangeSource, pub kind: ChangeKind }
#[derive(Debug, Clone, PartialEq)]
pub enum ChangeKind { Mounted, Unmounted, Action(String), Updated /* via Handle::update */, Relabeled }

/// Thread-safe registry. Cheap to clone (Arc inside). Send + Sync.
#[derive(Clone, Default)]
pub struct Ui { /* Arc<Inner> */ }
impl Ui {
    pub fn new() -> Self;
    pub fn mount<P: Primitive>(&self, primitive: P) -> Handle<P>;
    pub fn revision(&self) -> u64;                                    // global, bumps on every change event
    pub fn components(&self) -> Vec<ComponentInfo>;                   // mounted, ordered by id
    pub fn component(&self, r: impl Into<Ref>) -> Result<ComponentInfo, ResolveError>;
    pub fn resolve(&self, r: impl Into<Ref>) -> Result<ComponentId, ResolveError>;
    /// Ids mounted or changed after `revision`, plus ids unmounted after it.
    pub fn changes_since(&self, revision: u64) -> ChangeSet;
    pub fn invoke(&self, r: impl Into<Ref>, action: &str, args: impl Into<Args>, source: ChangeSource) -> Result<Value, InvokeError>;
    pub fn query(&self, r: impl Into<Ref>, query: &Query) -> Result<Option<Page>, ResolveError>;
    /// Veto hook run before every `invoke` (all sources). Returned guard removes it on drop.
    pub fn intercept(&self, f: impl Fn(&ActionRequest<'_>) -> Decision + Send + Sync + 'static) -> Subscription;
    /// Notified after every change. Returned guard removes it on drop.
    pub fn subscribe(&self, f: impl Fn(&ChangeEvent) + Send + Sync + 'static) -> Subscription;
}
#[derive(Debug, Clone, Default, PartialEq)]
pub struct ChangeSet { pub revision: u64 /* current */, pub changed: Vec<ComponentId>, pub removed: Vec<ComponentId> }

/// Typed handle to a mounted primitive. Clone; Send + Sync. Unmounts NOTHING on drop (explicit `unmount`).
pub struct Handle<P: Primitive> { /* ui: Ui (weak or strong — strong Arc is fine), id, PhantomData<fn() -> P> */ }
impl<P: Primitive> Handle<P> {
    pub fn id(&self) -> ComponentId;
    pub fn ui(&self) -> &Ui;
    /// Builder-style: `ui.mount(x).label("Mute")`. Emits Relabeled.
    pub fn label(self, label: impl Into<String>) -> Self;
    pub fn set_label(&self, label: impl Into<String>);
    /// Read state. Returns None if unmounted.
    pub fn read<R>(&self, f: impl FnOnce(&P) -> R) -> Option<R>;
    /// Mutate directly from app code (source given explicitly); bumps revision, emits Updated. No interceptors.
    pub fn update<R>(&self, source: ChangeSource, f: impl FnOnce(&mut P) -> R) -> Option<R>;
    /// Run an action by name with a source (goes through interceptors), same as Ui::invoke on this id.
    pub fn invoke(&self, action: &str, args: impl Into<Args>, source: ChangeSource) -> Result<Value, InvokeError>;
    pub fn unmount(self);
    pub fn is_mounted(&self) -> bool;
}
impl<P: Primitive> Clone for Handle<P>;  // manual impl, no P: Clone bound

/// Guard returned by intercept/subscribe. Dropping it unregisters. `detach(self)` keeps it forever.
#[must_use] pub struct Subscription { /* .. */ }
impl Subscription { pub fn detach(self); }
```

## Semantics that must hold (write tests for each)

1. Ids start at 1, increase, never reused after unmount.
2. Global revision starts at 0; mount/unmount/relabel/update/successful action each bump it by
   exactly 1 and set that component's revision to the new global value. A denied or failed
   action (Err) bumps nothing.
3. `invoke` order: resolve ref → check the action exists in `actions()` (else UnknownAction
   listing enabled actions) → check `is_enabled` (else `ActionError::Disabled`) → run all
   interceptors (first Deny wins → `InvokeError::Denied(reason)`) → call `Behavior::invoke`
   (None from invoke is treated as UnknownAction) → bump revision → notify subscribers.
4. Interceptors and subscribers are called WITHOUT the registry lock held, so a subscriber may
   call `ui.component(..)` or `handle.read(..)` without deadlock (test this). The component's own
   lock is held only during describe/invoke/read/update.
5. Lock poisoning must not panic the library: recover with `PoisonError::into_inner`.
6. `changes_since(r)` is correct for: a component changed twice (listed once), a component
   mounted then unmounted after r (in `removed` only), removed ids not in `changed`.
   Keep a bounded tombstone list (last 1024 unmounts) for removed tracking.
7. Ref resolution rules as documented above, including Ambiguous with candidate ids.
8. `Ui`, `Handle<P>` are `Send + Sync` (static assertion test).
