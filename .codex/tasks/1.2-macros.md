# Task 1.2 — `#[derive(Primitive)]` and `#[actions]`

Context: read `crates/rust-use-core/src` first (Behavior, Primitive, Describe, Args, ActionSpec,
ParamSpec, ActionError). Those are the traits you generate code for. **Do NOT run `git commit`.**
Work in `crates/rust-use-macros` (+ tests, + facade re-exports). Deps: syn 2 (full), quote,
proc-macro2 — declared in the workspace. Dev-deps: `trybuild = "1"` (add to workspace deps).

The point of these macros: a user writes ordinary Rust and gets an agent-drivable component
with zero boilerplate, and generated docs/specs are tight because they become agent tokens.

## Target usage (must compile exactly like this, via the facade `rust_use::prelude::*`)

```rust
use rust_use::prelude::*;

/// A button that mutes audio.
#[derive(Primitive, Default)]
#[primitive(name = "mute-button")]          // optional; default = kebab-case of the type name
struct MuteButton {
    #[agent(value)] muted: bool,            // primary value
    volume: u8,                             // shown as attr `volume=…` (default: every field is shown)
    #[agent(skip)] cache: Vec<u8>,          // never shown
    #[agent(rename = "lvl")] level: u8,     // shown as `lvl=…`
    #[agent(flag)] busy: bool,              // shown only when true, as a bare flag
    #[behavior] selection: Selection<u8>,   // embedded behavior: its describe/actions/invoke/query are merged
}

#[actions]
impl MuteButton {
    /// Mute or unmute.
    fn toggle(&mut self) { self.muted = !self.muted; }

    /// Set the volume (0–100).
    fn set_volume(&mut self, volume: u8) -> Result<(), ActionError> { … }

    /// Undo the last change.
    #[action(enabled = Self::can_undo)]     // path to `fn(&self) -> bool`
    fn undo(&mut self) { … }

    /// Rename (agent-visible name `rename_to`).
    #[action(name = "rename_to")]
    fn rename(&mut self, name: String, note: Option<String>) -> String { … }   // return values are serialized into the act result

    #[action(skip)]                          // ordinary method, not an action
    fn helper(&self) {}

    fn can_undo(&self) -> bool { … }        // methods taking &self (not &mut self) are never actions
}
```

(`Selection` does not exist yet; in tests use a small hand-written `Behavior` instead.)

## `#[derive(Primitive)]` generates

- `impl Behavior for T` and `impl Primitive for T { const NAME = "…"; }` using absolute paths
  through a re-export root. Use `::rust_use::__private` paths when used via the facade. Do this
  robustly: the derive emits paths rooted at `::rust_use_core` by default, but the facade defines
  `#[doc(hidden)] pub mod __private { pub use rust_use_core; }` and the derive accepts
  `#[primitive(crate = "path")]`. Simpler robust approach (preferred): use the `proc-macro-crate`
  crate to detect whether the user depends on `rust-use` (→ `::rust_use::__private::core`) or on
  `rust-use-core` directly (→ `::rust_use_core`). Add `proc-macro-crate = "3"` to workspace deps.
- `describe`: primary value from `#[agent(value)]` field (error if more than one), each shown
  field as `attr(name, &self.field)`, `#[agent(flag)]` via `flag`, then each `#[behavior]` field's
  `describe` is called on the same sink (behavior attrs merge in).
- `actions`: own actions (from `#[actions]`, via a hidden trait — see below) followed by each
  behavior's actions.
- `is_enabled`: own action → its `enabled` predicate (or true); else first behavior that lists it.
- `invoke`: own actions first; else try each behavior in field order; return the first `Some`.
- `query`: first behavior that returns `Some`.
- Field types must implement `serde::Serialize` unless skipped; emit a clear compile error span
  on the field if not (rely on the trait bound error; make sure the span points at the field).
- Errors with good spans for: enum/union input, tuple structs are OK (fields named `0`,`1` → attr
  names `_0`? NO: reject tuple structs with a clear message), unknown `#[agent(..)]` keys,
  two `#[agent(value)]` fields.
- If the type has no `#[actions]` block it must still compile: generate code that refers to a
  hidden trait `__OwnActions` with a *default impl provided by the derive only when*
  `#[primitive(no_actions)]` is given. Without `no_actions` and without `#[actions]`, the
  compile error must say: "add an `#[actions] impl` block or `#[primitive(no_actions)]`".

## Hidden trait in rust-use-core (add it there, `#[doc(hidden)]`, in a `__private` module)

```rust
#[doc(hidden)]
pub trait OwnActions {
    const ACTIONS: &'static [ActionSpec];
    fn own_is_enabled(&self, action: &str) -> Option<bool>;              // None = not ours
    fn own_invoke(&mut self, action: &str, args: &Args) -> Option<Result<Value, ActionError>>;
}
```

## `#[actions]` generates

- The impl block unchanged (minus our helper attributes), plus `impl OwnActions for T`.
- An action = method with `&mut self` receiver, not `#[action(skip)]`, any visibility.
- `ActionSpec { name, doc, params }`: `doc` = first paragraph of the doc comment, whitespace
  collapsed, trailing period kept. Missing doc comment is a compile error ("document this
  action: its doc comment is what the agent reads").
- `ParamSpec.ty` mapping: bool→"bool"; i8..i128,u8..u128,isize,usize→"int"; f32,f64→"float";
  String,&str→"str" (reject `&str` params with a clear error: use String); Option<T>→ty of T with
  optional=true; Vec<T>→"list"; anything else→"any".
- `own_invoke`: for each param, `args.get::<T>(i, "name")` or `get_opt` for Option. Return type
  handling: `()` → `Ok(Value::Null)`; `Result<T, E>` where `E: Into<ActionError>`... keep it
  simple: `Result<T, ActionError>` → map Ok via `serde_json::to_value` (error → Value::Null);
  any other `T: Serialize` → `Ok(to_value(t))`. Also accept `Result<(), String>` by implementing
  `From<String> for ActionError` (→ Rejected) in core; so generated code uses `.map_err(Into::into)`.
- Too many args supplied → `ActionError::InvalidArg { name: "args", reason: "expected N, got M" }`.
- Async methods / generics on methods → compile error with a clear message.

## Facade
- `pub use rust_use_macros::{Primitive, actions};` at root (feature `macros`) and in `prelude`.
  Note the derive macro and the trait share the name `Primitive` — that is intended (like serde's
  `Serialize`); make sure both are importable from the prelude at once.
- `#[doc(hidden)] pub mod __private { pub use rust_use_core as core; pub use serde_json; }`.
  Generated code must not require the user to depend on serde_json directly.
