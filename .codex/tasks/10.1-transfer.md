# Task 10.1 — `Transfer`: move items between named lists

Read AGENTS.md, `crates/rust-use-core/src/behaviors/{mod.rs,list.rs,selection.rs}` (follow their
pattern exactly: a `const` action table, the `action`/`param`/`dispatch` helpers, a typed API for app

Reordering within one list already exists (`List`'s `move <from> <to>`). `Transfer` covers kanban
boards, two-pane pickers ("available / selected") and playlists with folders: several named lists in
one component, and items moving between them in one agent action.

## API (contract)
```rust
/// Items arranged in named lists, moved within and between them.
pub struct Transfer<T> { /* lists: Vec<(String, Vec<T>)>, accept: Option<Box<dyn Fn(&T, &str) -> bool + Send>> */ }
impl<T> Transfer<T> {
    pub fn new() -> Self;
    pub fn with_list(self, name: impl Into<String>, items: Vec<T>) -> Self;   // builder; names unique (later duplicate replaces)
    pub fn accept(self, f: impl Fn(&T, &str) -> bool + Send + 'static) -> Self; // veto moves into a list
    pub fn lists(&self) -> impl Iterator<Item = (&str, &[T])>;
    pub fn list(&self, name: &str) -> Option<&[T]>;
    /// Move the item at `index` of list `from` to list `to` at `at` (end when None).
    pub fn move_item(&mut self, from: &str, index: usize, to: &str, at: Option<usize>) -> Result<(), ActionError>;
}
impl<T: PartialEq> Transfer<T> {
    /// Find an item by value: (list name, index).
    pub fn find(&self, item: &T) -> Option<(&str, usize)>;
}
```
Agent side (`T: Serialize + DeserializeOwned + PartialEq + Send + 'static`):
- describe: one attr per list, `<name>=<count>`, in list order (short; contents are reached through `query`).
- action `move(item:any, to:str, at:int?)`: finds the item by value (an agent knows items by
  what they are, not by index), then moves it. Errors are `Rejected` with a reason that helps
  recovery: unknown list (list the names), item not found, refused by `accept`, index out of range.
  Add an optional-parameter helper `param_opt` next to `param` in `behaviors/mod.rs`.
- `queryable() -> true`. `query`: `Query.text` of the form `<list>` or `<list> <filter>` pages the
  items of that list; with no text, it pages `"<list>: <item>"` across all lists.
- Override `owns` to scan the const table.
