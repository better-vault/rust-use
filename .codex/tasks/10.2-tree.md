# Task 10.2 — `Tree`: expand, collapse and select by path

Read AGENTS.md and `crates/rust-use-core/src/behaviors/{mod.rs,list.rs,selection.rs}` (follow the
same pattern), and `crates/rust-use/tests/behaviors.rs`. **Do NOT run `git commit`.**

## API (contract)
Nodes are addressed by **path**: their labels joined with `/`, e.g. `src/agent/format.rs`. An agent
already knows paths, so it never needs ids or a sequence of expands to reach a node.
```rust
pub struct Tree<T = ()> { /* nodes with label, data T, children, expanded flag; selected: Option<path> */ }
impl<T> Tree<T> {
    pub fn new() -> Self;
    /// Build from paths ("a/b/c"), creating intermediate nodes with T::default().
    pub fn from_paths<I: IntoIterator<Item = S>, S: AsRef<str>>(paths: I) -> Self where T: Default;
    pub fn insert(&mut self, path: &str, data: T) -> Result<(), ActionError>; // parent must exist or is created
    pub fn remove(&mut self, path: &str) -> Option<T>;
    pub fn get(&self, path: &str) -> Option<&T>;
    pub fn expand(&mut self, path: &str) -> Result<(), ActionError>;   // also expands ancestors
    pub fn collapse(&mut self, path: &str) -> Result<(), ActionError>;
    pub fn select(&mut self, path: &str) -> Result<(), ActionError>;   // also expands ancestors so it is visible
    pub fn selected(&self) -> Option<&str>;
    pub fn is_expanded(&self, path: &str) -> bool;
    /// Rows a person sees right now, depth-first: (depth, path, has_children, expanded).
    pub fn visible_rows(&self) -> Vec<TreeRow<'_>>;
    /// Move a node (and its subtree) under a new parent ("" = root) at an index.
    pub fn move_node(&mut self, path: &str, parent: &str, at: Option<usize>) -> Result<(), ActionError>;
}
pub struct TreeRow<'a> { pub depth: usize, pub path: String, pub label: &'a str, pub has_children: bool, pub expanded: bool }
```
Labels must not contain `/`: `insert` rejects them with a clear error.

Agent side (`T: Send + 'static`; data is never shown):
- describe: attrs `sel=<path>` when selected, and `open=<n>` (the number of expanded nodes). Keep it short.
- actions: `expand(path:str)`, `collapse(path:str)`, `select(path:str)`, `move(path:str, parent:str, at:int?)`.
  Unknown paths → `Rejected("no node at <path>; children of <nearest existing ancestor>: a, b, c")`
  so an agent can recover in one call.
- `queryable() -> true`. `query` text is a path prefix or a substring; returns matching **paths**,
  including nodes under collapsed branches (agents reach closed branches without expanding them).
- Override `owns`.

## Tests
`from_paths`, `expand` (expands ancestors), `visible_rows` order and depth, `select` reveals the
node, `move_node` (including refusing to move a node into its own subtree), and the recovery error
text. Embedding test: a file-tree primitive driven with `agent.act("files select src/agent/format.rs")`,
checking the snapshot line, plus `query files format` finding the node under collapsed branches.
