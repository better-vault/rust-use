## `Range`: a bounded number, or a span of two
```rust
pub struct Range { /* min, max, step: f64; value: f64; end: Option<f64> for two thumbs */ }
impl Range {
    pub fn new(min: f64, max: f64) -> Self;          // step defaults to 1.0; value = min
    pub fn step(self, step: f64) -> Self;            // > 0, else treated as continuous (step 0 = any value)
    pub fn span(self, start: f64, end: f64) -> Self; // turns on two thumbs
    pub fn value(&self) -> f64;
    pub fn bounds(&self) -> (f64, f64);              // (start, end) for a span; (value, value) otherwise
    /// Clamp to [min, max] and snap to the step from min. Returns the stored value.
    pub fn set(&mut self, value: f64) -> f64;
    pub fn set_span(&mut self, start: f64, end: f64) -> Result<(f64, f64), ActionError>; // start <= end after snapping
    pub fn increment(&mut self); pub fn decrement(&mut self);   // one step, for keyboard handlers
}
```
Agent side: describe `value` (single) or `value = [start, end]` (span), plus attrs `min`, `max`,
`step` (omit `step` when it is 1). Integral numbers render without `.0`: serialize as an integer when
`fract() == 0`. Actions: `set(value:float)`; `set_span(start:float, end:float)` only when it is a
span (`is_enabled` false otherwise). An out-of-range `set` **clamps** and returns the stored value
(the act reply shows `=> 1 100`), and is not an error. NaN → `InvalidArg`.

## `Tabs`: one selected tab, and the panel that follows it
Built on `Selection<String>` in single mode, which it embeds.
```rust
pub struct Tabs { /* tabs: Vec<String>, selection */ }
impl Tabs {
    pub fn new<I: IntoIterator<Item = S>, S: Into<String>>(tabs: I) -> Self; // first tab selected
    pub fn selected(&self) -> &str;
    pub fn select(&mut self, tab: &str) -> Result<(), ActionError>;   // unknown tab → Rejected listing the tabs
    pub fn tabs(&self) -> &[String];
    pub fn is_visible(&self, tab: &str) -> bool;   // the panel to render
    pub fn next(&mut self); pub fn prev(&mut self); // wrap, for arrow keys
}
```
Agent side: describe value = the selected tab, attr `tabs=[a,b,c]`. Action `select(tab:str)`. Override `owns`.

## Tests
`Range`: clamping, snapping (min 0, step 5, set 12 → 10, set 13 → 15), span ordering, continuous
step 0, NaN, rendering (`=40 min=0 max=100`, and a span `=[20,80]`). `Tabs`: select, unknown tab
error text, next/prev wrap. Embedding tests through `agent.act` with exact snapshot lines.
