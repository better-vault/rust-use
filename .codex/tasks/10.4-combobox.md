## `Combobox`: pick from a long list, or type your own
```rust
pub struct Combobox<T> { /* options: List<T>, value: Option<T>, free_text: Option<String>, allow_free_text: bool, open: bool */ }
impl<T> Combobox<T> {
    pub fn new(options: Vec<T>) -> Self;
    pub fn free_text(self, allowed: bool) -> Self;
    pub fn options(&self) -> &List<T>;
    pub fn value(&self) -> Option<&T>;
    pub fn text(&self) -> Option<&str>;          // free text, when that was entered instead
    pub fn open(&mut self); pub fn close(&mut self); pub fn is_open(&self) -> bool;
    pub fn clear(&mut self);
}
impl<T: PartialEq> Combobox<T> { pub fn pick(&mut self, option: T) -> Result<(), ActionError>; } // must be an option
```
Agent side (`T: Serialize + DeserializeOwned + PartialEq + Send + 'static`):
- describe: value = the picked option or the free text; attr `n=<option count>`; flag `open`.
- actions: `pick(option:any)`. Matching is exact on the value. When the value is a string, also
  accept a case-insensitive exact match. When nothing matches, return `Rejected` with up to 5 closest
  options (by `query` text matching) so the agent can retry in one call.
  `type(text:str)` is enabled only when free text is allowed. `clear` is enabled only when something is set.
- `queryable() -> true`; `query` pages options by text (reuse `List`'s query).
- Override `owns`. Picking closes the popup.

## Example: `crates/rust-use/examples/agent_tour.rs` (features: macros + agent; no GPUI)
A small "project settings" screen mounting one primitive per 0.2 behavior: `Tabs` (General /
Members / Notifications), `Range` (volume), `Combobox` (country, over ~250 country names hard-coded
as a const slice), `Tree` (files), and `Transfer` (kanban: todo / doing / done). It prints the
snapshot, runs ONE batched `agent.act(..)` that touches all five, prints the reply, and then a
`query` on the combobox. Under 150 lines, documented at the top, and runnable with
`cargo run -p rust-use --example agent_tour`. Add `required-features = ["macros", "agent"]`.
