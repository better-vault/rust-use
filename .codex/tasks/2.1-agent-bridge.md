## Public API (contract)

```rust
// crates/rust-use-agent/src/lib.rs re-exports flat:
pub struct Agent { /* ui: Ui, last_seen: AtomicU64 (or Mutex<u64>), _guard: Option<Subscription> for allow */ }
impl Agent {
    pub fn new(ui: &Ui) -> Self;
    /// Only let the agent run actions the predicate accepts. Installs a `Ui::intercept`
    /// that applies to ChangeSource::Agent requests only. Builder-style; can be chained
    /// (all predicates must allow).
    pub fn allow(self, f: impl Fn(&ActionRequest<'_>) -> bool + Send + Sync + 'static) -> Self;
    pub fn snapshot(&self) -> Snapshot;                         // marks last_seen = current revision
    pub fn snapshot_with(&self, opts: SnapshotOptions) -> Snapshot;
    pub fn diff(&self) -> Diff;                                 // since last_seen, then updates last_seen
    pub fn diff_since(&self, revision: u64) -> Diff;            // does not touch last_seen
    pub fn act(&self, script: impl Into<Script>) -> Result<ActOutcome, ActError>;
    pub fn query(&self, target: impl Into<Ref>, text: Option<&str>, from: usize) -> Result<QueryOutcome, ResolveError>;
    /// Execute one line of the text protocol (snapshot | snapshot --verbose | diff | act <script> | query …)
    /// and return the text reply. This is what transports (IPC, MCP, CLI) call.
    pub fn handle(&self, request: &str) -> String;
}

/// Extension so users write `ui.agent()`.
pub trait UiAgentExt { fn agent(&self) -> Agent; }
impl UiAgentExt for Ui { … }

#[derive(Debug, Clone, Copy, Default)] pub struct SnapshotOptions { pub docs: bool }

/// Parsed form; Display renders FORMAT.md text exactly.
#[derive(Debug, Clone, PartialEq)] pub struct Snapshot { pub revision: u64, pub components: Vec<ComponentInfo> /* + docs flag */ }
#[derive(Debug, Clone, PartialEq)] pub struct Diff { pub revision: u64, pub changed: Vec<ComponentInfo>, pub removed: Vec<ComponentId> }
// Both: impl Display, and `to_json(&self) -> serde_json::Value` for MCP structured content.

/// A batch of steps. From<&str>/From<String> parse the text syntax lazily (parse errors surface
/// from act as ActError::Parse). From<Step>, From<Vec<Step>>, From<[Step; N]>.
pub struct Script { … }
#[derive(Debug, Clone, PartialEq)] pub struct Step { pub target: Ref, pub action: String, pub args: Args }
pub fn step(target: impl Into<Ref>, action: impl Into<String>, args: impl Into<Args>) -> Step;

#[derive(Debug, Clone, PartialEq)] pub struct ActOutcome { pub values: Vec<(usize, Value)> /* non-null step results */, pub diff: Diff }
// Display: "ok\n" + "=> i v" lines + diff

#[derive(Debug, Clone, PartialEq, thiserror::Error)]
pub enum ActError {
    #[error("parse error at {line}:{column}: {message}")] Parse { line: usize, column: usize, message: String },
    #[error("step {index}: {source}")] Step { index: usize /* 1-based */, step: String /* rendered "@2 move e2e5" */, #[source] source: InvokeError, diff: Diff /* what earlier steps changed */ },
}
// ActError::to_reply(&self) -> String renders "err <i> <step>: <message>\n<diff>" per FORMAT.md.

#[derive(Debug, Clone, PartialEq)] pub struct QueryOutcome { pub page: Option<Page> }  // Display per FORMAT.md; None → "not queryable"
```

## Module layout
```
format.rs   value encoding (bare/quoted strings, numbers, lists, objects), component line rendering, param rendering
parse.rs    tokenizer + script parser (refs incl. quoted labels and @ids, args per value syntax, ; and newline separators, comments `#` to end of line allowed)
agent.rs    Agent, UiAgentExt, handle()
types.rs    Snapshot, Diff, Script, Step, ActOutcome, ActError, QueryOutcome
```

## Details
- `act` invokes every step with `ChangeSource::Agent`. Diff is computed with `Ui::changes_since(rev_before)`.
- Error message for UnknownAction/illegal values must be the core error's Display (which lists available actions) — do not lose information.
- `handle()` never panics; unknown command → `err unknown command `<x>` (try: snapshot, diff, act, query)`.
- Rendering must be allocation-conscious: write into one `String` with `fmt::Write`; no intermediate Vec<String> per attr.
- Token budget tests (`tests/budget.rs`): mount 20 mixed components (hand-written primitives in the test), assert snapshot byte length is below a committed threshold, and assert a diff after a single action contains exactly one component line. Use `insta = "1"` (add to workspace dev-deps) snapshot tests for the exact rendering of a representative screen, and for every example in FORMAT.md (make them pass byte-for-byte; if FORMAT.md is internally inconsistent, follow the more compact reading and note it in your final message).
- Round-trip property: for random values (strings with spaces/quotes/unicode/numeric-looking text, ints, floats, bools, null, nested lists), `parse_value(format_value(v)) == v` (except float formatting normalization). A small hand-rolled generator over a fixed seed list is fine; no proptest dependency needed.
