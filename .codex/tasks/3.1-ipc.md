# Task 3.1 — Local IPC: serve a running app to out-of-process agents

Read first: `crates/rust-use-agent` (Agent, `Agent::handle`, FORMAT.md) and `crates/rust-use-core`.
**Do NOT run `git commit`.** You have no network; all crates you need are in the local cargo
cache: `interprocess = "2"` (2.4.x). Read its source under `~/.cargo/registry/src/*/interprocess-2*`
for the exact API rather than guessing.

## Why
An agent such as Claude Code runs in another process. It must reach the bridge inside a
running GPUI app in well under a millisecond per call, with no server process in between.
This is the "native" transport the benchmark compares against MCP.

## Where
`crates/rust-use-agent/src/ipc/{mod,server,client,endpoint,frame}.rs`, behind a new
`ipc` cargo feature on rust-use-agent (`interprocess` optional dep). Facade feature
`ipc = ["agent", "rust-use-agent/ipc"]` re-exports `rust_use::ipc::*`.

## Wire protocol
- Frame = `u32` little-endian byte length + UTF-8 payload. Max frame 16 MiB (reject larger with an error frame, then close).
- Request payload: exactly the text `Agent::handle` accepts (`snapshot`, `snapshot --verbose`,
  `diff`, `act <script>`, `query …`) or a custom command registered on the server.
- Response payload: the text reply.
- One `Agent` session per connection (its own last-seen revision). Connections are handled on
  their own threads (std threads; no async runtime in the library).

## Endpoints
```rust
/// Where a server listens. Name-based, cross-platform via interprocess local sockets.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Endpoint { name: String }
impl Endpoint {
    /// `name` must match [a-z0-9-]{1,40}. Error otherwise.
    pub fn new(name: &str) -> Result<Self, IpcError>;
    /// Value of env `RUST_USE_APP`, else the current executable's file stem sanitized.
    pub fn from_env() -> Self;
    pub fn name(&self) -> &str;
}
```
- On Unix, use a filesystem socket at `$XDG_RUNTIME_DIR/rust-use/<name>.sock`, falling back to
  `$TMPDIR/rust-use-$UID/<name>.sock` (or `std::env::temp_dir()` + `rust-use-<uid>`). Create the
  directory with mode 0700 and remove a stale socket file before binding if no server answers.
  On Windows, a named pipe `rust-use-<name>` (interprocess namespaced name).
- `pub fn list_endpoints() -> Vec<Endpoint>` lists live sockets in that directory (Unix); on
  Windows returns an empty Vec (document it).

## Server
```rust
pub struct Server { … }
impl Server {
    pub fn new(ui: &Ui) -> Self;                         // endpoint = Endpoint::from_env()
    pub fn endpoint(self, endpoint: Endpoint) -> Self;
    /// Extra commands for app-specific endpoints (the chess demo uses this for its baseline
    /// automation tree). `name` is the first word of the request; handler gets the rest.
    pub fn command(self, name: &'static str, handler: impl Fn(&str) -> String + Send + Sync + 'static) -> Self;
    /// Builder: apply an allow predicate to every connection's Agent (same semantics as Agent::allow).
    pub fn allow(self, f: impl Fn(&ActionRequest<'_>) -> bool + Send + Sync + 'static) -> Self;
    /// Called after every request is answered, on the connection thread. The chess demo uses
    /// this for its live metrics panel (calls, bytes, latency per transport).
    pub fn observe(self, f: impl Fn(&RequestLog<'_>) + Send + Sync + 'static) -> Self;
    /// Bind and accept on a background thread. Dropping the returned guard stops accepting and removes the socket file.
    pub fn spawn(self) -> Result<ServerGuard, IpcError>;
}
pub struct ServerGuard { … }   // Drop: stop + cleanup. `endpoint(&self) -> &Endpoint`.

/// One answered request, as seen by `Server::observe`.
#[derive(Debug)]
pub struct RequestLog<'a> { pub request: &'a str, pub reply: &'a str, pub elapsed: std::time::Duration, pub connection: u64 }
```
Note `Agent::allow` installs an interceptor per Agent. For the server, install ONE interceptor
for the server's lifetime instead of one per connection (keep it in ServerGuard).

## Client
```rust
pub struct Client { … }
impl Client {
    pub fn connect(endpoint: &Endpoint) -> Result<Self, IpcError>;
    /// Connect to the only live endpoint; error listing candidates if zero or several.
    pub fn connect_default() -> Result<Self, IpcError>;
    pub fn request(&mut self, payload: &str) -> Result<String, IpcError>;

#[derive(Debug, thiserror::Error)] pub enum IpcError { … Io(#[from] std::io::Error), InvalidName(String), NoServer, Ambiguous(Vec<String>), FrameTooLarge(usize) }
```

## Tests (`crates/rust-use-agent/tests/ipc.rs`, `#![cfg(feature = "ipc")]`)
- Round trip: spawn a server for a Ui with two hand-written primitives on a unique endpoint
  name (include the test pid), connect, `snapshot`, `act`, `diff` — replies equal what
  `Agent::handle` returns in-process.
- Two clients have independent `diff` sessions.
- Custom `command` works; unknown command returns the Agent's error text.
- `allow` denies through IPC.
- Frame larger than the max → error, server keeps serving other clients.
- Latency smoke: 1,000 sequential `snapshot` requests on a 20-component Ui complete in < 2 s on CI (prints the per-call mean).
- Dropping ServerGuard removes the socket file (Unix).
