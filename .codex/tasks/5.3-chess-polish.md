# Task 5.3 — Chess demo visual polish

Read `demos/chess/src/view/*` and compare with the reference `demos/chess/assets/reference/board-reference.png`.
The architect ran the app and found these issues. Fix exactly these. **Do NOT run `git commit`.**

1. **Pieces too heavy.** The reference's dark pieces are soft charcoal, not pure black, and the
   outlines are dark grey rather than black. Edit the twelve SVGs in `demos/chess/assets/pieces/`:
   in the black pieces (`b*.svg`) replace fill `#000`/`#000000`/`black` with `#4A4846` and keep
   the white inner detail strokes (`#fff`) as they are; in all pieces replace stroke
   `#000`/`#000000` with `#2E2C2A`. White piece fills stay `#fff` but use `#F8F8F8`.
   Do it with a small, careful script and verify each file still parses (load all twelve through
   `usvg` in a unit test — usvg is already a transitive dependency via gpui; if it is not directly
   usable, check by building the app and rely on the architect's visual check). Add a line to
   `demos/chess/assets/pieces/LICENSE.md`: "Colours adjusted to match the demo's palette."
2. **Agent traffic table**: label and value collide ("Mean latency229 µs"). Lay rows out as a
   two-column grid per transport with the label left, value right-aligned, a minimum 8px gap, and
   shorten the label to "Latency". Use tabular figures if gpui supports a monospace/tabular font
   feature; otherwise use the monospace font for values only.
3. **Buttons**: "New game" and "Undo" must share one style (filled `#3A3835`, text `#E8E6E3`,
   hover `#45433F`, 8px radius); disabled = 40% opacity and no hover. Currently they look like
   two different kinds of button.
4. Window title in the titlebar duplicates the header; keep the header, set the window titlebar
   to transparent/unified if gpui 0.2.2 supports `TitlebarOptions { appears_transparent: true }`
   and leave ~28px top padding for the traffic lights.

Acceptance: full gate passes; `cargo build -p chess-demo` works. Keep the changes small.
