# Task 9.4 — Readability pass and a self-testing core tarball

Read AGENTS.md. **Do NOT run `git commit`.** No behavior changes in this task.

## Part A: blank lines between items (formatting only)
Several files written in 0.1 have no blank line between items: between `impl` blocks, between
methods, between a struct and its `impl`, and between top-level `fn`s. This hurts readability.
In every `.rs` file under `crates/*/src` and `demos/*/src`, put exactly one blank line between
consecutive items (fns, impls, structs, enums, consts, mods, `use` groups and the first item, trait
methods with bodies). Do not reflow code, rename anything, reorder items, or touch logic. Run
`cargo fmt --all` afterwards.

Verify the change is formatting only: `git diff --stat` should show only insertions of blank lines.
Check with `git diff -U0 | grep '^[-+]' | grep -v '^[-+][-+]' | grep -v '^+$'`, which must print
nothing apart from rustfmt adjustments, and those you must list in your final message.

## Part B: the published rust-use-core tarball must pass its own tests
`crates/rust-use-core/tests/macros.rs` uses `rust-use-macros`, a path-only dev-dependency that
`cargo package` strips, so `cargo test` inside the published tarball fails. Move those tests to
`crates/rust-use/tests/` (the facade already depends on both crates), adapting the imports to the
facade's `rust_use::prelude::*`, and remove the dev-dependency from rust-use-core. Do the same
check for `rust-use-macros` (its dev-dependency on core is path-only too): its trybuild tests need
core, so add `exclude = ["tests/*"]` to rust-use-macros' `[package]` if they cannot run from the
tarball, with a comment saying why.

Verify:
```sh
cargo package -p rust-use-core --allow-dirty --no-verify
mkdir -p target/tarball-check && tar -xzf target/package/rust-use-core-*.crate -C target/tarball-check
# The extracted crate sits inside our workspace directory; an empty [workspace] table makes it its
# own root, and CARGO_TARGET_DIR reuses our build cache instead of starting a new one.
(cd target/tarball-check/rust-use-core-* && echo '[workspace]' >> Cargo.toml \
  && CARGO_TARGET_DIR=../../tarball-target cargo test --offline)
rm -rf target/tarball-target
rm -rf target/tarball-check target/package
```

## Acceptance
The full gate passes. List any rustfmt changes beyond blank lines in your final message.
